# Minicurso - LaTeX

Esse repositório foi criado para armazenar conteúdo adicional e exemplos de código
para um minicurso ministrado no dia 16-10-2026. Tudo disponível aqui é código

Só abrir uma issue ou enviar um e-mail pra um de nós.\

seus primeiros documentos acadêmicos em LaTeX.

Esperamos sinceramente que este conteúdo ajude você de alguma forma.
